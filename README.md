# Interdict

Working title for a single-player space captaining game: a salvage crew, a banned AI aboard, a patron with a hidden agenda. Ships behave like submarines in space (heat, light-lag sensors, silent running).

This repository holds the playable prototypes. The design lives in two docs:

- Concept doc: "Game Concept: Salvage Crew"
- Slice spec: "Vertical Slice: One Sortie"
- Roadmap: "Development Roadmap: Interdict"

## Layout

- `sim/` game rules, no screen code (runs headless)
- `web/` browser pages
- `data/` lines, cards and scenes as plain files
- `BUILD_LOG.md` one-page log read at the start of every session
